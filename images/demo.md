# Markdown, in place

Read and edit **bold text**, *emphasis*, `inline code` and [links](https://github.com/rjprins/markdown-modern) in one buffer.

## Keep writing

- [x] Read styled Markdown
- [ ] Put the cursor on a checkbox and press Space
- Edit source by moving into a heading, link or code block

## Tables stay aligned

| Feature | Reading | Editing |
|---------|---------|---------|
| Headings | Styled text | Reveal the markers |
| Tables | A clear grid | Edit one row in place |
| Code | Syntax highlighting | Keep the source close |
